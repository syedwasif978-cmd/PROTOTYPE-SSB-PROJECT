# PROTOTYPE-SSB-PROJECT

## Workspace Layout

- `frontend/` - Next.js prototype UI for the AI Excel chatbot
- `backend/` - Minimal Node.js API stub for prototype endpoints

## Run Locally

- Frontend: `npm run dev --workspace frontend`
- Backend: `npm run dev --workspace backend`

The frontend folder is Vercel-ready and contains its own deployment config.
